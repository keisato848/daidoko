## 採点基準の欠陥を1つ見つけた（重要）

C（家庭で作れるか）の定義が、**レシピ自身が代替を明示している場合**をどう扱うか決めていなかった。
v1 は実際に代替を書いていた（バイマックルー→省略可、黒カルダモン→グリーンカルダモンで代用可、
パームシュガー→きび砂糖）。レシピが代替を教えるなら作れるので、当初 C=1 としたのは厳しすぎた。

**「代替が明示され日本のスーパーで完結するなら C=2、専門店・専用器具が代替なしで残るなら C=1」**
に統一し、v0/v1 の両方を同じ基準で採点し直した。これは設計 §3 が警告していた
「測ってから基準を作ると自分に甘くなる」の実例であり、**基準の文言が曖昧だったこと自体が欠陥**。
設計に定義を追記済み。

## 思考トークンはほぼ効いていない

思考オフでコストが **41%**（¥0.85 → ¥0.35）になり、品質差は A で -0.04、他は同等。
**-0.04 は 23 件中 1 件の差**で、統計的に区別できない。間違えた中身が入れ替わっているだけだった。

|          | 思考あり          | 思考オフ              |
| -------- | ----------------- | --------------------- |
| 担々麺   | ✅ 汁なし担々麺   | ❌ 炸醤麺             |
| 唐揚げ   | ✅ 鶏の唐揚げ     | ❌ 鶏むね肉のフリット |
| 生姜焼き | ❌ 豚肉の甘辛炒め | ✅ 豚バラ肉の生姜焼き |

思考オフのほうが**代替提案は丁寧**だった（豆豉→省略可、コチュジャン→焼肉のたれ、
パルミジャーノ→粉チーズ、牛骨→鶏手羽元でも可）。石焼ビビンバの材料も 43 → 30 個に整理された。

**含意**: 思考オフにすれば同じ月 ¥918 の予算で上限を 30 回/日 → 87 回/日にできる。
ただし n=23 の易しいセットでの結果であり、難しい写真では思考が効く可能性は残る。**いま切ると断定はできない**。

## v1 で直ったこと / 悪くなったこと

**直った**: 担々麺（台湾風肉そぼろまぜ麺 → 汁なし担々麺）／筑前煮（根菜と鶏肉の五目煮 → 筑前煮）／
きんぴら（3品盛り合わせ・材料20 → 材料11）／カツカレーの材料からポテトサラダ等が消えた／
**陰性ケースが理由を返すようになった**（not_food / ingredients_only）。

**悪くなった**: C が -0.04。**v0 が書いていた「タマリンドペースト→なければレモン汁で代用」を v1 が落とした**。
指示が増えて競合した結果と思われる。
また v1 は 27 件すべてを high と申告した（v0 は 2 件が medium）。**自信の表明が一律になった**のは
confidence を基準で判定させた副作用の可能性がある。

## この結果で判断できないこと

**R4（ストア刷新）には進めない。** 3 変種とも全項目を通過したのは、設計 §3 の但し書きどおり
「合格」ではなく**基準が緩かった証拠**として扱う。実写真（暗い店内・無名の創作料理）での再測定が必要。
