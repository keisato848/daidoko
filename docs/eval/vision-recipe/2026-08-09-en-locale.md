### C の判定基準を英語向けに読み替えている

日本語版の C は「日本のスーパーで完結するか」。英語版では
**「英語圏のスーパーで完結するか」**で判定した。同じ基準では英語圏の利用者にとって
意味がないため。この読み替えを明記しておかないと、次回の測定と比較できない。

## 減点の中身（3 件・すべて C）

| id  | 料理           | 減点            | 理由                                                     |
| --- | -------------- | --------------- | -------------------------------------------------------- |
| h03 | たこ焼き       | C=1             | たこ焼き器に**代替の明示がない**（ja も C=1・同じ理由）  |
| h05 | きんぴらごぼう | C=1             | ごぼうに代替の明示がない（英語圏ではアジア食材店が必要） |
| h08 | 筑前煮         | A=1 / B=1 / C=1 | **Nishime（煮しめ）として出力**。鶏肉と人参が落ちた      |

**h08 が唯一の実質的な劣化。** 筑前煮と煮しめは近い料理だが別物で、
英語では「Nishime」に寄せた結果、筑前煮に必須の鶏肉が材料から消えた。
日本語版は「筑前煮」と正しく特定し鶏もも肉を入れている。

一方で **h04・h05 は英語のほうが正確**だった。

- h04 生姜焼き: ja は「豚肉の甘辛炒め」（説明的な言い換え → A=1）、en は "Ginger Pork (Shogayaki)" → A=2
- h05 きんぴら: ja は切り干し大根・油揚げを足していた（B=1）、en は ごぼう＋人参のみ → B=2

## 出力言語の指示が効いていること（実例）

- **両単位の併記**: `1 block (about 14-16 oz / 400-450g)` `2 cups (480ml)`
- **入手困難な食材の代替**: `Mitsuba (Japanese parsley) — Or substitute with thinly sliced green onions`
- **器具の代替**: `a large paella pan or a wide, shallow skillet` / `If you don't have a dolsot, …`
- **推定の明示（v1 の要求）が英語でも維持**: `Dashi stock — Presumed. Can use dashi granules dissolved in hot water.`

## 判断

**英語での公開に品質上の障害はない。** ラインはすべて満たしており、
A・B・confidence 校正はむしろ日本語より良い。

ただし **C は 1.87 とラインぎりぎり**で、これは日本語版と同じ。
減点はいずれも「日本料理を英語圏の材料で作る」ことの難しさに由来し、
プロンプトの不具合ではない。英語圏向けに評価セットを組み直せば C は上がるはずで、
**逆に言えば今回の C は日本料理に偏った評価セットでの下限に近い**。
