### 個人開発アプリの目安（比較用・外部記録）

- 広告なし・1 年継続の例: 最初の 2 か月は月 50 前後、3 か月目以降は月 100〜200 件

- 20 本以上出した開発者の経験則: リリース数日で 1 日 1 桁なら、コンセプトから変えないと動かない
  （[たかもブログ](https://takam0.hatenablog.com/entry/2018/03/01/%E5%80%8B%E4%BA%BA%E9%96%8B%E7%99%BA%E3%81%A7%E3%82%B9%E3%83%9E%E3%83%9B%E3%82%A2%E3%83%97%E3%83%AA%E3%82%9220%E6%9C%AC%E4%BB%A5%E4%B8%8A%E9%96%8B%E7%99%BA%E3%81%97%E3%81%A6%E3%81%8D%E3%81%A6%E3%80%81)）

「機能が良ければ放っておけば伸びる」は成り立たない（ストアは勢いのあるアプリを上に出す。新規・評価 0 は面に出ない）。

## 2. 2026-09-05 に新しく分かったこと（Gmail と Web 検索。ストア API はリモート環境から遮断されていて未確認）

### 2-1. 【期限 2026-09-30】Play の「Android デベロッパーの確認」— アプリ登録が済んでいるか未確認

- 2026-06-01 の Play Console メール: **「0 個のアプリが登録済み・2 個のアプリが自動登録の対象外だったため登録が必要」**
  （当時は公開前だったので対象外になった可能性が高い）
- 2026-08-07 リマインダー、**2026-09-04 最終リマインダー**（一斉配信文面）。
  期限 **2026-09-30**。未登録のアプリは **全世界の Play から削除される**
- リポジトリのどこにも追跡されていない（`docs/` を grep して 0 件）
- **対処**: Play Console ホームで `com.daidoko.app` の登録ステータスを見る。未登録なら
  「Android デベロッパーの確認」ページから登録する。**流入の話より先にこれ。** 済んでいたら本節にその旨を書く

### 2-2. App Store の 1.13.0 は「だいどこ - 献立・レシピ管理・買い物リスト・在庫」で公開済み

- ASC メール（2026-09-03「Ready for Distribution」）で確認。決定変更 B のとおり
- `docs/store/app-store/SUBMISSION.md` の到達点表（App 名の行）は「お店の味を再現…」のままだったので追記した

### 2-3. 「だいどこ」単独は既存ブランドと衝突する（Web 検索面）

Web で「だいどこ アプリ レシピ」を検索すると、**パルシステムの「だいどこログ」**（レシピサイト＋Android アプリ＋Instagram、
2011 年頃〜）が上位を占める。Play 内の指名検索「だいどこ」では 1 位（8/26 調査）なので**ストア内は問題ない**。
問題は**記事・SNS・口コミからストアへ辿り着く経路**で、「だいどこ」とだけ聞いた人が Google で探すとそちらへ流れる。

- 対処: 記事・SNS・LP では **「だいどこ - 献立・レシピ管理」のように補語をつけて呼ぶ**。改名はしない

### 2-4. 掲載文の一般語は競合が押さえている（Web 検索面でも同じ）

「レシピ管理 買い物リスト 献立」で Web 検索すると App Store / Play の結果はレピッタ・レピモ・クックスルー・レシパル・買いさぽ。
だいどこのストアページはアプリ名の完全一致でも出てこない。8/26 調査の「各検索語で圏外」と整合。

### 2-5. 「〇〇 再現レシピ」は検索される語だが、完成レシピは既に大量にある

「サイゼリヤ 再現」「丸亀製麺 再現」はクックパッド特集・Yahoo ニュース・ブログ・YouTube Shorts・TikTok が埋めている。
レシピそのものを出しても埋もれる。書く余地があるのは「写真 1 枚から出た下書きを感想で 2〜3 回直した**過程**」で、
この形の記事は見当たらなかった（2026-09-05 の Web 検索の範囲）。ただし決定変更 B の後は主語が献立なので、
記事の題材も「冷蔵庫の写真から今日の献立」（1.13.1 の冷蔵庫枠）の方が掲載と一致する。§5 参照。

### 2-6. AdMob「メッセージの適用範囲を最大化する」が 2026-09-24 頃に自動有効化

2026-08-25 の AdMob メール。パーソナライズ広告対象外トラフィックへの同意メッセージ設定が自動で入る。
EEA/英国は配信除外済み（`docs/海外展開の検討.md` §2-3）なので影響は小さいが、AdMob の「プライバシーとメッセージ」を一度見ておく。
