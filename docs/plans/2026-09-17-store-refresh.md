## 目的

**「表示 → 閲覧」を上げること。** 検索結果の面（アイコン・アプリ名・サブタイトル・先頭スクショ・
フィーチャーグラフィック）と、その先で価値が伝わる素材（スクショ列・動画・掲載文）を、
いまのプロダクトの姿に合わせ直す。

**目的でないもの**（取り違えない）:

- 閲覧 → DL の改善（実測 14〜16.67% で相場並み。ここは詰まっていない）
- インストール数そのもの（リーチが律速で、掲載改修だけでは絶対数は動かない。
  `流入の記録` §3 が「掲載改修だけで待たない」と明記している）

### iOS 側の制約（2026-09-17 に ASC API で実測）

`appStoreVersions` は 1.13.2 / 1.13.1 / 1.13.0 / 1.12.0 / 1.11.0 **すべて `READY_FOR_SALE`**。
`PREPARE_FOR_SUBMISSION` のバージョンが 1 つも無い。
→ **iOS のアプリ名・サブタイトル・説明・キーワード・スクショは、次のバージョンを作らないと変えられない**
（`READY_FOR_SALE` を編集しようとすると Apple が 409 STATE_ERROR を返す）。
**`promotionalText` だけは審査なしで変えられる。**

**Play と iOS で「先行できる範囲」が非対称**なので、Q5（段取り）の選択肢はこの前提で読む必要がある。
