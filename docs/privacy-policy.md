# だいどこ プライバシーポリシー

最終更新日: 2026-09-01

「だいどこ」（以下「本アプリ」）は、家庭内で利用するレシピ手帳アプリです。本ポリシーは、本アプリがどのような情報を取り扱うかを説明するものです。

## 1. 本アプリが取り扱う情報

本アプリでは、ユーザーが入力または作成した以下の情報を端末内に保存します。

- レシピ情報（タイトル、材料、手順、メモ、タグなど）
- 調理記録（評価、メモ、調理日時など）
- 料理写真、OCR 取り込み元テキスト、写真取り込み元情報
- 家族グループ名、表示名、招待コードなどのアプリ内設定情報
- 買い物リスト、在庫（食材名・数量・期限など）、食材名の対応表
- ローカルバックアップおよび移行用バックアップに含まれるデータ

これらの情報は、ユーザーがレシピの保存、閲覧、編集、バックアップ、復元を行うために利用されます。

## 2. 権限の利用目的

本アプリは、以下の権限をユーザーの明示操作時にのみ利用します。

- カメラ: レシピ写真や調理記録写真の撮影、OCR 取り込み、商品バーコードの読み取りのため
- 写真ライブラリ: 端末内の画像を選択し、レシピ作成や調理記録、AI 解析に利用するため
- ファイル選択: 移行用バックアップファイルを選択して復元するため
- 通知: 料理タイマーの終了、在庫の残量が設定したしきい値を下回った際のお知らせ、自動献立モードの朝のお知らせ、調理を中断したときの再開案内のため。**これらはいずれも端末の中で作られる通知**で、サーバーや外部サービスを経由しません（家族共有の更新通知については 3.5 をご覧ください）

## 3. 外部送信される情報

### 3.1 URL 取り込み機能

ユーザーが「URL から取り込み」機能を使う場合、入力した URL は本アプリのサーバーに送信されます。サーバーは、その URL のページを取得してレシピ情報を抽出し、下書きデータを端末へ返します。

この処理は、URL 取り込み機能を提供する目的のためにのみ行います。

### 3.2 AI 解析機能（写真・テキスト）

以下の AI 機能では、対象のデータが本アプリのサーバーへ送信され、AI 解析サービス（Google Gemini API）で処理されます。**最後の「食材名の名寄せ」以外は、ユーザーがその機能を実行したときにだけ送信されます。**

- 写真からレシピ作成: 選択した料理写真 1 枚、および入力した補足テキスト（店名・感想など・最大 1000 文字）
- 紙面からレシピ作成（レシピ本・食品パッケージ）: 選択した紙面の写真（1 回に最大 4 枚）、および入力した補足テキスト（最大 1000 文字）
- お店の味に近づける: 対象レシピの内容全体（タイトル・説明・人数・調理時間・材料の名前と分量と注記・手順の本文・タグ）、入力した感想（最大 1000 文字）、および添付した写真（最大 2 枚）
- 相談してレシピを作る: 会話のやりとり（直近 24 件までの、ユーザーと AI の発言）、添付した写真（直近 4 枚まで）、**相談中に作られている下書きレシピの内容全体**（タイトル・説明・人数・調理時間・材料の名前と分量と注記・手順の本文・タグ）、および「在庫を考慮する」を選んだ場合は在庫の食材名（最大 200 件）
- レシピの表紙イメージ生成: レシピのタイトル・材料名（最大 20 件）・タグ（最大 5 件）。**写真は送信しません**
- 食事写真からの在庫消費推定（「食べた」機能）: 選択した食事写真
- レシートの読み取り: 端末内の文字認識が使える場合はその読み取りテキスト全文（店名や食品以外の行を含みます）、使えない場合は選択したレシート写真
- 食材名の名寄せ（表記ゆれの解決）: 在庫に登録した食材名と、レシピに書かれた材料名のテキスト（**名前だけ**で、数量・期限・レシピの本文は送信しません）

上記のうち、ユーザーが実行する機能の画面には、外部へ送信されること・保存されないことを**常に表示しています**（以前は初回に同意ダイアログを出していましたが、操作のたびに割り込むため画面上の常時表示に変えました）。送信されたデータは解析処理のためにのみ利用され、本アプリのサーバーには保存されません（解析後に破棄されます）。AI 解析サービスにおける取り扱いは Google のプライバシーポリシーに従います。

**食材名の名寄せだけは、ユーザーが実行を指示しなくても行われます。** 「この在庫で作れるレシピ」の画面を開いたとき、および「足りない材料を買い物リストへ」を実行したときに、在庫の食材名とレシピの材料名の突き合わせが機械的なルールでは付かなかった名前だけが、自動的に送信されます（送るのは名前のテキストのみ・1 日あたりの件数上限あり）。この機能だけは画面上の常時表示ではなく、本ポリシーと「設定 → データ → 名寄せ辞書」画面の説明で案内しています。AI が覚えた対応は同画面で確認・修正・削除できます。名寄せだけを止める設定は現在ありません（オフラインのときは送信されず、突き合わせは端末内のルールだけで行われます）。

なお、無料利用枠を数えるため、一部の AI 機能のリクエストにはランダムに生成した端末の識別子が付きます。氏名・メールアドレス等とは結び付きません。

なお、設定から自分の Gemini API キー（BYOK）を登録した場合、写真・テキストは本アプリのサーバーを経由せず、ユーザー自身のキーで Google Gemini API に直接送信されます。

「文字入り画像から作成」は、以前は端末内で文字認識していましたが、現在は上記の「紙面からレシピ作成」として写真を送信します（画面に明示しています）。レシートの読み取りは端末内の文字認識を優先し、読み取れた場合は**写真は端末から出ず、読み取ったテキストだけ**を送ります。端末内の文字認識が使えない・読み取れない場合のみ、画面上で明示したうえで写真を送ります。

### 3.3 共有機能

ユーザーが共有操作を行った場合、本アプリは以下の情報を OS の共有機能に引き渡します。

- 家族グループの招待コード
- ユーザーが作成した移行用バックアップファイル

共有先となるアプリやサービスでの取り扱いは、各サービスのプライバシーポリシーに従います。

### 3.4 Web 共有（レシピ共有ページ）

ユーザーが「Web ページで共有」を明示的に実行した場合に限り、対象レシピの内容（タイトル・材料・手順・メモ・タグ・写真）が本アプリのサーバーに保存され、発行された URL を知っている人だけが閲覧できる Web ページとして公開されます。

- 共有ページに氏名・端末情報などの個人情報は含まれません
- 共有ページは検索エンジンに登録されない設定（noindex）で提供されます
- ユーザーはいつでもアプリから共有を停止できます。停止すると、URL を知っている人でもページと写真は表示されなくなります（レシピ帖に有効期限を設定した場合、期限切れでも同じく表示されなくなります）。**止め方は共有したものの種類によって違います**（5.1）
- **ただし、停止・期限切れによってサーバー上のデータが消えるわけではありません。** 公開したときの内容（タイトル・材料・手順・メモ・タグ・写真）は「取り消し済み」の印が付いた状態でサーバーに残ります（自動的に消去する仕組みは設けていません）。控えの消去をご希望の場合は 11. の連絡先へご連絡ください
- 共有された内容は、共有ページの表示のためにのみ利用されます

### 3.5 家族共有（クラウド同期）

ユーザーが「共有グループを作る」または「招待コードで参加する」を明示的に実行した場合に限り、以下のデータが本アプリのサーバーに保存され、同じグループに参加している端末どうしで同期されます。

- レシピ（タイトル・材料・手順・メモ・タグ・出所）とレシピ帖
- 買い物リストと在庫のうち、ユーザーが「家族」として共有している品目（品目ごとに「自分だけ」にでき、その品目は端末から出ません）
- 食材名の対応表（表記ゆれの解決に使う辞書）
- 端末の識別子（ランダムに生成した ID）、通知の表示言語、最終同期時刻、および端末が取得できた場合は通知の送付先（プッシュ通知トークン。下記のとおり現在の公開版では取得されません）

家族共有では**アカウントを作りません**。氏名・メールアドレス・電話番号などの個人情報はサーバーに保存されず、グループの参加には招待コードのみを使います。写真は現時点ではサーバーに保存されません（端末内にのみ残ります）。

**共有データが更新されたことを知らせるプッシュ通知は、現在の公開版では配信していません。** サーバーから「共有データが更新されました」という固定の文面（誰が何を変えたかは含みません）を送る仕組みはありますが、その配信に必要な設定が未了のため、端末は通知の送付先（プッシュ通知トークン）を取得できず、通知も届きません。同期は通知に依存せず、アプリの起動時・再表示時・データの書き込み後に行われます。

- 同期されたデータは、グループの端末へ配信するためにのみ利用されます
- ユーザーはいつでもグループから離脱でき、離脱しても端末内のデータは残ります
- グループの作成者が**グループを削除**すると、家族共有のためにサーバーへ置かれたデータ（このセクションで挙げたもの）はすべて消去されます。最後の端末が離脱した場合も同様に消去されます
- **Web 共有（3.4）で公開したページは別の保管場所にあり、グループの削除では消えません。**
  公開したページの削除は 3.4 のとおり、共有の停止で行ってください
- 90 日以上同期していない端末はグループから自動的に外れます（端末内のデータは残ります）
- 通信は暗号化（HTTPS）されます

### 3.6 広告（AdMob）

本アプリは、AI 機能の無料利用枠を増やすための任意の広告（リワード広告）に Google AdMob を利用します。広告の表示にあたり、AdMob は広告 ID（Advertising ID）などの識別子を利用します。詳細は Google の広告に関するポリシーをご確認ください。

広告の視聴は任意です。視聴しなくても本アプリの機能は利用できます。

### 3.7 AI が作ったものの報告

ユーザーが AI の生成物について「報告する」を実行した場合に限り、選んだ報告の種類（不適切／不正確／その他）、入力した本文（最大 500 文字）、報告元の画面名、および端末の識別子（ランダムに生成した ID）が本アプリのサーバーへ送信されます。

- 報告の内容は、サーバーの運用ログと運営者への通知メールに残ります（他の外部送信と違い、これは**保存されます**）
- 報告されたレシピや画像そのものは送信されません（本文にユーザーが書いた場合を除きます）
- 氏名・連絡先は求めていません。本文に個人情報を書かないでください

## 4. 実装していない機能

現在のアプリ公開版では、以下を目的とした SDK または機能は実装していません。

- アプリ利用状況の解析やトラッキング（Firebase Analytics 等）
- ユーザーの行動履歴に基づくプロファイリング
- 献立の AI による並べ替え（コードはありますが**無効にしてあり**、献立のために外部へ送信されるデータはありません）。献立は在庫と調理記録をもとに端末内で組み立てます

## 5. 保存場所と保持期間

- レシピ、メモ、写真、バックアップなどのアプリデータは、主にユーザーの端末内に保存されます。
- ユーザーが削除しない限り、これらのデータは端末内に保持されます。
- アプリをアンインストールした場合、端末内のアプリデータは OS の仕様に従って削除されることがあります。
- **家族共有（3.5）を利用している場合**、同期対象のデータは本アプリのサーバー（データベース）にも保存されます。保持期間はグループが存在する間で、グループの削除または最後の端末の離脱により消去されます。削除した項目の「削除された」という記録（内容は含みません）は、他の端末へ削除を伝えるために残ります。
- **Web 共有（3.4）を利用している場合**、共有ページの内容（写真を含みます）はサーバーに保存されます。共有を停止するか有効期限が切れると誰も閲覧できなくなりますが、**サーバー上の控えはそのまま残ります**（停止は「取り消し済み」の印を付ける処理で、自動的に消去する仕組みは設けていません）。**これは家族共有とは別の保管場所で、家族グループを削除しても消えません。** 閲覧を止める方法と、控えの消去を求める方法は 5.1 のとおりです。
- **AI が作ったものの報告（3.7）を送った場合**、報告の内容（種類・本文・報告元の画面名・端末の識別子）はサーバーの運用ログと運営者への通知メールに残ります。
- URL 取り込み機能の利用時には、サーバー側で処理に必要な通信が発生します。運用上必要な範囲で、サーバーの基本的なアクセス記録が残る場合があります。

### 5.1 データの削除を求めるには

サーバーに置かれるデータは**家族共有と Web 共有の 2 つに分かれており、消し方も別々**です。
片方を消しても、もう片方は残ります（このほか、AI 生成物の報告（3.7）の内容が運用ログに残ります）。

- 家族共有（3.5）のデータ: アプリの「家族グループ」画面で、作成者が「共有グループを削除」を実行すると、家族共有のためにサーバーへ置かれたデータが消去されます。作成者でない場合は「このグループから離脱」でご自身の端末を外せます（他の端末が残っている間、共有済みのデータはサーバーに残ります）。
- Web 共有（3.4）の閲覧を止める: **グループの削除では止まりません。** 公開したものの種類によって、停止する場所が違います。
  - レシピ 1 品の共有: そのレシピの詳細画面のメニューから「Web共有を停止」（**「設定 → レシピ帖」の一覧には出ません**）
  - レシピ帖（複数のレシピを 1 冊にまとめたもの）の共有: 「設定 → レシピ帖」の一覧から停止
  - 公開したものが複数ある場合は、ひとつずつ停止してください
- Web 共有（3.4）のサーバー上の控えを消す: **アプリからは行えません。** 停止しても控えは残るため（3.4・5.）、消去をご希望の場合は 11. の連絡先へ、対象の共有 URL を添えてご連絡ください。
- そのほかアプリ内で操作できない場合も、11. の連絡先またはストアの掲載ページに記載の連絡先までご連絡ください。

## 6. 第三者サービス

本アプリは、機能提供のために以下のような外部サービスまたは外部システムと連携する場合があります。

- ユーザーが指定したレシピサイト
- ユーザーが選択した共有先アプリ
- 本アプリのサーバーホスティング環境

## 7. AI が生成するレシピについて（重要）

本アプリの「写真からレシピ作成」「お店の味に近づける」などの機能は、**AI による推定**でレシピを生成・調整します。実際に作られた料理を分析したものではなく、**内容の正確性を保証するものではありません**。

### 7.1 アレルギー・食物過敏症について

**本アプリは、アレルゲンの検出・除去・警告を行いません。**

AI が生成した材料には、次のような場合があります。

- 写真から判別できない材料（だし・油・調味料の原材料など）が含まれている
- 「もっとコクを出したい」といった感想に応じて、乳製品・ナッツなどが**追加される**
- 一般的な代替材料として、意図しない食材が提案される

**食物アレルギー・食物過敏症をお持ちの方、およびそうした方に料理を提供する場合は、AI が生成した材料をそのまま信頼しないでください。** 必ずご自身で全ての材料を確認し、実際に使用する製品の原材料表示をご確認ください。

### 7.2 調理と安全について

加熱時間・温度・保存方法などの調理条件も AI による推定です。食品衛生上の安全（十分な加熱、生食の可否、保存期間など）については、**公的機関の情報やご自身の判断を優先してください**。

### 7.3 免責

AI が生成したレシピの利用によって生じた結果について、本アプリは責任を負いません。生成されたレシピは**下書き**としてご利用いただき、内容の確認と調整はご自身の責任で行ってください。
