## 1. F17 の訂正は妥当（WCAG 1.4.4 で補強できる）

| 項目 | 内容 |
| --- | --- |
| 状態 | 採用（補強） |
| 重大度 | mid |
| 指摘 | F17 の訂正は妥当。ただし WCAG には最小フォントサイズの規定が無い一方、**1.4.4（テキストのサイズ変更）が 200% 拡大での動作を求めている**。10px はコントラスト比が高くても老眼の物理的可読性を満たさない |
| 調査 | WCAG 2.1 SC 1.4.4 は「200% まで拡大してもコンテンツ・機能を失わない」を要求。現行の受入基準 C-5（端末の文字サイズ最大で一巡）はこれに対応する検証だが、**根拠として 1.4.4 を明示していなかった** |
| 判断 | 当たり。F17 の結論は変わらないが、C-5 に規格上の裏付けが付く |
| 対応 | 受付票 C-5 に「WCAG 2.1 SC 1.4.4 相当」を追記済み |

| 項目 | 内容 |
