## 第 0 部: 聞く前に実物で確かめたこと

質問を成り立たせるために先に調べた。**ここは推測ではなく実測・実ファイル。**

### 0-1. 生成機能（→ 詳細は `docs/store/gemini-generation-2026-09-17.md`）

- **画像生成は使える**（`agy` の `generate_image`）。日本語の見出しが崩れずに出る。ブランド色も出る
- **動画・音声・字幕の生成は `agy` からは使えない**（モデル一覧・ツール一覧に無い）
- **スクショを AI に作らせるのは不可**。実画面を渡しても描き直され、UI が誤字になる
  （実測: 「玉ねぎの期**限**が近いから」→「期**服**」、タブバーの「在庫」「買物」が崩壊）

### 0-2. いま漏れている段階は「表示 → 閲覧」で、そこは掲載の顔が担当している

`docs/growth/流入の記録.md` の実測（2026-09-10 取得）。

| 段階      | iOS 実測                    | 相場     |
| --------- | --------------------------- | -------- |
| 表示→閲覧 | **2.04%**（検索経由 1.61%） | 7〜8%    |
| 閲覧→DL   | 14%（Play は 16.67%）       | 相場並み |

**2026-09-05 に「掲載スクショ・文言の再改修はしない」と判断している**が、その根拠は
**閲覧→DL の 16.67%**（＝製品ページは詰まっていない）だった。
いま 4 分の 1 に落ちているのは**その 1 つ前の段階**で、同記録 §1-3 は原因を
「検索語（Apple Ads の自動選択）か**検索結果の面（アイコン・名前・サブタイトル）**か、依然未分離」としている。
**過去の判断が間違いだったのではなく、見ていた段階が違う。** 今回はここを対象にできる。

### 0-3. スクショ 8 枚はすべて素のキャプチャ。帯付き版を作る仕組みは既にあるが使われていない

- Play/App Store に上がっている 8 枚は、エミュレータの生キャプチャそのまま（キャプション無し・枠無し）
- 一方 `scripts/generate-play-promos.mjs`（`sharp` + SVG）は、**実スクショに日本語の見出しを焼いた
  1080×2400 の「販促版」を生成できる**。出力は `docs/store/google-play/promotional-screenshots/` に 6 枚ある
- ただし `docs/store/google-play/assets.md` はその用途を「**提出前の比較、SNS 告知、追加訴求案の叩き台**」と
  書いており、**掲載に採用しない判断をした記録は無い**。中身も古い（旧スクショ・旧コピー「家族の台所が一冊に」）
- **つまり「素のまま上げ続けている」のは決定ではなく、既定のまま来ただけの可能性が高い**

### 0-4. 見つけた食い違い（答えを待たずに直す候補）

- **フィーチャーグラフィック（ja/en とも）が旧訴求のまま。** 画に「AI RECIPE FROM A PHOTO /
  写真を撮るだけで、レシピが完成。」と焼かれている。これは
  ① 2026-08-28 の決定変更 B（主語を「お店の味」→「献立」）より前の訴求で、
  ② `listing-ja.md` の 1.13.1 追記が明文で禁じている言い回し
  （「**『撮るだけで作れる』という言葉は使わない**」— Gemini の CM が刷り込んだ語で、真似ると
  「なら Gemini でいい」を招く）に該当する。**掲載文と掲載画像で訴求が割れている**
- **プロモ動画も旧訴求のまま。** `scripts/release/edit-promo-video.mjs` の `CUTS` を読むと、
  実尺 **約 18.5 秒**・7 カットで、字幕は
  「旅先で撮った写真から」→「えらぶだけで」→「AI がレシピを下書き」→「料理中は次の一手だけ」→
  「家族の台所を、ひとつの手帳に」→「いつでもすぐ検索」→「買い物・在庫までひとつに」。
  **献立も冷蔵庫も 1 カットも無い。** 掲載文の主語（献立）と動画の主語（写真からレシピ）が割れている
- **まとめると、掲載の「絵」の面は 3 つとも決定変更 B 以前のまま**（フィーチャーグラフィック・
  プロモ動画・スクショの装飾）。**文章だけが献立へ動き、絵が付いてきていない**
- **App Store のアプリ名が旧 ASO 名のままの疑い。** `docs/store/app-store/listing-ja.md` に
  「アプリ枠には旧 ASO 名で登録してしまっているので変更が必要」とメモがある。
  ただし**メモは書いた時点の記録であって現在値ではない**（`なぜインストールされないか-2026-08-26.md` の教訓）。
  ASC API で現在値を引いてから扱う
