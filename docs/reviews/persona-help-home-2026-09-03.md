# ホームのヘルプ点検 — ペルソナ5人の統合（2026-09-03 / 1.13.0 系）

前回監査: [ux-help-currency-2026-08-31.md](ux-help-currency-2026-08-31.md)（A1/A2 は 1.13.0 で出荷済み）。
今回はその後に増えた UI（献立カード等）に対する再点検。

## 全員が踏んだ・複数人が踏んだ順

### P1. 「＋」が 2 つあり、案内はどちらか特定しない（5人中5人）

**症状** — コーチマーク1枚目は右下 FAB をハイライトするが、文言は「「＋」から始めます」
としか言わず、画面には FAB と下部中央「追加」タブの 2 つの「＋」が同時に見える。
スマホ不慣れ層は「毎回迷う・操作ミスの元」、几帳面層は「どちらか確信できない」。

**原因** — 前回監査 B1 の「＋が2つ」重複がそのまま。文言も位置を言わない。

**対処** — 本命は B1 どおり FAB 削除（重複解消）。文言だけの応急は
「右下の「＋」か下の「追加」タブ — どちらも同じ入口」と両方を明示する（本 PR で実施）。

### P2. コーチマークの機能名が画面の実表記とズレている（3人）

**症状** — 案内は「写真からAI作成・AIと相談」だが、画面のボタンは
「料理の写真を撮る」「AIと相談しながらつくる」。同じ機能か別の機能か初見で判断できない。

**原因** — ホームのクイックアクション追加時に、コーチマーク側の列挙を追随させなかった。

**対処** — 案内の列挙を画面の実表記に寄せる（本 PR で実施）。

### P3. 献立カードに説明が一切ない（4人）

**症状** — ホーム最上部の「献立」カードはコーチマークで触れられず、
「タップできるのか、ただのバナーなのか分からない」「材料未入力で何が起きるか不明」。

**原因** — 献立 M1 がコーチマーク無しで出荷（前回監査 §2-4 が予告していた事態）。
かつ B5（コーチマーク版管理が無い）のため、後から足しても既存ユーザーには出ない。

**対処** — 文言では直らない。B5 の版管理を入れてから home のコーチマークに1枚足すか、
カード自体の affordance（タップ可能に見える形）を直す。**本 PR ではやらない**（UI 変更・要判断）。

### P4. 「家族と共有されているものはどれか」がホームで分からない（1人・ただし利用者の実指摘と同型）

**症状** — 記録カードの「プロフィール未設定」表示では誰の記録か分からず、
招待されただけの家族メンバーには「妻の記録なのか、サンプルなのか」が判別できない。

**対処候補** — 表示名未設定のときの表示を「わたし」等に倒す／家族グループ参加時に
表示名入力を促す。共有範囲の全体像は family 画面のダイアログにあるが、ホームからは見えない。

### P5. ヘッダの暦・写真・?、下部タブ（在庫・買物）が未説明（3人）

**対処** — 前回監査 §3-1「ヘルプを増やして解決しない」に従い、コーチマーク追加はしない。
暦/写真は B1 の「ビュー切替に畳む」で自然に説明不要になる。買物・在庫はタブ名が自明。

## 次アクション（提案）

1. 本 PR: P1 応急・P2 の文言修正（i18n のみ）
2. 判断待ち: B1（FAB 削除・暦/写真の畳み込み）と B5（コーチマーク版管理）→ P3 の献立1枚
3. 判断待ち: P4（表示名未設定の見せ方）
