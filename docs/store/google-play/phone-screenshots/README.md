# Google Play スマホ用スクリーンショット

Google Play はスマホ用スクショを**最大 8 枚**まで。このフォルダ直下の 8 枚を
この順番でアップロードする。**1〜3枚目で「推し機能＝写真からレシピ」の
ストーリー（結果の説得力→仕組み→編集可能な下書き）を見せ、以降で家族の
蔵書・料理体験を見せる構成**（2026-07-14 ASO監査で並び替え。旧順は末尾参照）。

**機械的な再取得とアップロード**（詳細は `docs/リリース手順.md` §3-2）:

- 取得: `node scripts/release/capture-store-screenshots.mjs`（サンプルデータ入り
  リリース APK ＋ 1080x2400 エミュレータ `daidoko_e2e_fresh_api36` 前提）
- 反映: `node scripts/release/update-play-screenshots.mjs`（下表の順にアップロード。
  順序を変えるときはスクリプトの ORDER 配列も併せて更新）
- `08` と `10` は自動化対象外（manual）— 既存 PNG を維持する。手で撮るときも
  ステータスバーは同じデモモードに揃える（`.claude/skills/update-store-listing` §スクリーンショット）

| 順  | ファイル                     | 内容                                         |
| --- | ---------------------------- | -------------------------------------------- |
| 1   | `10-recipe-detail-photo.png` | 料理写真つきレシピ詳細（ヒーロー・実写掲載） |
| 2   | `07-photo-to-recipe.png`     | 写真からレシピ（導線・AIの仕組み説明）       |
| 3   | `08-photo-recipe-result.png` | 写真からつくったレシピの編集可能な下書き     |
| 4   | `01-home-timeline.png`       | ホーム（家族の調理タイムライン）             |
| 5   | `02-recipe-library.png`      | レシピ蔵書庫（一覧・検索）                   |
| 6   | `03-recipe-detail.png`       | レシピ詳細                                   |
| 7   | `04-cooking-mode.png`        | 料理中モード                                 |
| 8   | `06-family-group.png`        | 家族グループ                                 |

旧順（2026-07-04〜07-13）: 01→02→03→04→06→07→08→10。
ASO監査で「1枚目が汎用画面で推し機能(AI写真レシピ)が8枚中6〜8番目に埋もれている」
と判明し変更（検索結果グリッドは1枚目だけが露出するため）。

## 現在の中身（2026-08-26 更新・1.12.0 / versionCode 10029）

**AQUOS SH-RM19s の実機・1080x2432** で撮り直した（旧: エミュレータ 1080x2400）。理由:

- #217 / #219 が入って **ボトムタブに「買物」が増えた** — 全 8 枚に写るので撮り直しが必要だった
- 蔵書・ホーム・詳細に**実際の料理写真**が入るようにした。
  「写真からレシピ」で店で食べた料理 6 品（カルパッチョ・アヒージョ・ポテト・ガトーショコラ・
  ポレンタフリット・ガレット）を作り、その写真がヒーロー画像になっている

`10` / `08` / `04` は**同じカルパッチョ**で揃えてある（1〜3 枚目の
「結果 → 仕組み → 下書き」が同じ料理で繋がるように）。

## extras/（アップロード対象外）

8 枚に収めるため以下は `extras/` に退避（必要なら差し替え可）。

- `05-ocr-import.png` — 旧 OCR 取り込みの画面。#212 で AI 化したため**内容が古い**。
- `09-recipe-library-photos.png` — `02-recipe-library` と内容が重複。
- `11-shopping-list.png` — 買い物リスト（#219 で独立タブ化）。8 枠に空きが出たら差し替え候補。
