## 先に直すべき欠陥が 2 件見つかった（実測）

調査の副産物だが、**これが今回いちばん実利のある発見**。

### 1. US ストアフロントが日本語のまま

```
country=us → trackName = 「だいどこ - お店の味を再現するレシピ・買い物リスト」
             description も日本語
```

配信は **jp と us の 2 つだけ**なので、**半分のストアフロントが未翻訳**。
ASC に英語(米国)のローカライズが無く、日本語にフォールバックしている。

**Play 側には既に en-US の掲載文がある**（`docs/store/google-play/listing-en.md`）ので、**原稿は流用できる**。

### 2. 製品ページの「言語」欄が英語単独

```
languageCodesISO2A = ['EN']   ← jp / us とも
```

**日本語で書かれた日本のアプリの製品ページに「言語: 英語」と出ている。**
しかも中身は **ja/en 完全対応済み**（949 件を辞書化・PR#142）。**実装と申告が真逆。**

原因は `apps/mobile/app.json`:

```
expo.locales               → 未設定
ios.infoPlist              → ITSAppUsesNonExemptEncryption のみ
CFBundleLocalizations      → 未設定
```

バイナリが対応言語を宣言していないため、App Store が英語単独と判定している。

### 直すコスト — **単独ではできない**

ASC ヘルプに **"You can manage languages only when the app status is editable"** とあり、
editable なのは _Prepare for Submission_ と _Waiting for Review_ だけ。
**公開中の 1.12.0 には足せない＝1 リリースサイクルに乗る作業。**

→ **次のリリースに相乗りさせる以外に安く済ませる方法が無い。**
`CFBundleLocalizations` の追加は `app.json` 変更なので **`--prebuild` 必須**。

## C. Apple Ads $100 — やる。ただし「インストール施策」ではない

### ⚠ 最重要の警告 — **$100 で自動的に止まらない**

Apple の逐語: **"You will be responsible for paying the remaining balance"**

**支払い方法の登録が配信開始の条件で、超過分は自分のカードに請求される。**
「クレジットが尽きたら止まる」仕組みは無い。**放置すると自腹課金になる。**

### 得られるもの

- **十数件〜60 件程度、中心は 30〜40 件**（$100 ≈ ¥15,900・$1=¥159.28 / 2026-08-26）
- 根拠は**すべて二次**（日本 CPI $2.57 / AppTweak 2025、日本の個人開発アプリ実測 CPA ¥1,074 / 2025-10）
- **流れは変わらない。クレジットが尽きれば元に戻る**

### Basic か Advanced か

**前回「Advanced 推奨」と書いた根拠は捨てる** — 引用した TTR/CVR の事例は**出典が存在しなかった**。
Apple 自身の比較ページはむしろ **Basic を個人開発者向け、Advanced を "more expertise" 向け**としている。

**Advanced を選ぶ理由は「検索語レポートが取れる」の 1 点だけ。**
Basic のレポートはインストール数と平均 CPI のみ・API 非対応。

**見張り方も違う**: Basic は月予算に上限が効く（減額は翌月から・翌カレンダー月に自動再開するので手で pause）。
Advanced に月予算欄は無く日次予算制で、**「日によって日次予算を超える」と Apple が明記**。

## やらないこと

- **PR TIMES** — 個人事業主には開業届の提出を求められる。無料枠「スタートアップチャレンジ」は個人事業主を明示的に対象外
- **Google Play インディー枠** — 選定条件が "developer based in the United States" かつ "user rating of 4.0 stars or higher"。**二重に資格が無い**
- **バリュープレスの無料枠** — 配信先 20 媒体。**個人の可否と住所公開の要否が公式ページで確認できなかった**ので触らない
- **個人開発者向けディレクトリ**（FindUpApp / izanami / Solomaker 等）— 稼働中・無料だが**読者が同業の個人開発者**。利用者層と重ならない
- **知人・家族に評価を頼む** — 実際に使っていない人に星を付けてもらうのは**操作行為とみなされうる**。
  「評価と報酬の連動はポリシー違反」で一度設計をやり直しているので、同じ轍。
  **実際に使った人が自分の言葉で書く**形以外はやらない
- **App Preview 動画を今作る** — 7 項目の 1 つではあるが、**転換率は既に 16.67%（平均並み）で律速はリーチ**。半日〜1 日を今投じる価値は薄い
