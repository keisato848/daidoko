# だいどこ — 海外展開の検討

> 作成: 2026-08-06
> ステータス: 検討（着手判断はまだ）

英語圏への展開を検討した際の、事実確認・判断・決定事項の記録。
**判断の前提は時間が経つと理由ごと忘れるため、根拠を残す。**

---

## 1. まず事実確認（推測を書かない）

2026-08-06 に Play Console で実測した。**それまでの「日本のみ配信」という認識は誤りだった。**

| 項目             | 実際                                                          |
| ---------------- | ------------------------------------------------------------- |
| 配信国           | **177 か国 / 地域**（アイルランド・アイスランド・米国を確認） |
| アカウント種別   | **プライベート（非販売者）**                                  |
| 登録住所         | Google に登録済み。**Play には表示されない**                  |
| 公開される連絡先 | メールアドレスのみ                                            |

つまり **UI が日本語なだけで、配信はすでに全世界**。EU/EEA も含む。

これは Play の既定（全世界配信）をそのまま使っていたため。意図した設定ではない。

### ここから導かれること

- **EEA 向けの広告同意（UMP/CMP）は、すでに必要な状態で稼働している。**
  `ad-reward.admob.ts` に `AdsConsent.gatherConsent()` はあるが、
  「日本のみだから不要」と誤認していたため**実効検証をしていない**
- データセーフティ申告・プライバシーポリシーも、実際には全世界向けとして審査を通っている
- 住所公開は現時点では発生していない（非販売者として登録されているため）

## 2. 決定事項

### 2-1. 外国語版を出すときは EU を対象外にする

**理由**: 判断を複雑にする要素が EU に集中しているため。

- **DSA の販売者情報開示** — 現在は「プライベート（非販売者）」で住所非公開。
  ただしアプリは**広告収益を得ている**。販売者と再分類された場合、
  住所の公開が必要になりうる。収益化方針A（広告のみ）を選んだ理由が
  **自宅住所の公開回避**（2026-07-06 決定）なので、ここは触らない
- **GDPR** — 写真・レシート（購買履歴）を AI に送る構成の説明責任が重い
- **AI Act / 改正製造物責任指令** — AI が生成した**調理手順**は健康被害に直結しうる。
  ソフトウェアが製造物責任の対象に明示された影響を、日本国内配信では意識せずに済んでいた

英語圏でも**米・加・豪・NZ・シンガポール等**は対象にできる。EU を外しても市場は残る。

> **現在の日本語版も EU に配信されている。** 外国語版の話とは別に、
> いま EU を外すかどうかは別途判断が要る（§6 の未解決論点）。

### 2-2. アプリアイコンは海外版で変える

現在のアイコンは **臺所**（正字体）＋湯気の立つ椀。

**問題**: 「臺」は正字体で、欧米の利用者には「**中国語のアプリ**」と読まれる。
日本の家庭料理アプリとしては誤ったシグナルであり、読めず記憶にも残らない。

**方針**: **湯気の立つ椀を主役にする。** これは 2026-07-14 の ASO 監査で
「48–96px で消えない太さ・面積が必要」と学んだ要素で、言語に依存しない。

文字を入れるなら `DAIDOKO`（Cormorant Garamond Italic）だが、
**縮小時に判読不能**という実績がある（同じ監査で欧文副題を外した理由）。
文字なし・椀のみが有力。

> ブランド規定（`docs/brand/ロゴ仕様.md` §「ロゴ・アイコン・スプラッシュ = 臺所」）は
> **日本語版の規定として維持**し、海外版を例外として併記する。

## 3. ニーズとの適合（論理の検討）

### 核の需要は日本より大きい

英語圏の **copycat recipe** は確立したジャンルで、需要の層は日本の「再現レシピ」より厚い。

### ただし勝てるのはロングテール

チェーン店の再現レシピは、**人間が実際に試作した記事**が無料で大量にある。
写真1枚からの AI 推論はそれに勝てない。

差別化が成立するのは**個人店・旅先・既存レシピが存在しない料理**。
本当に空白だが、市場は copycat 需要の総量よりかなり狭い。

### 写真→レシピはコモディティ

**汎用 AI アシスタントに料理写真を送れば、無料でレシピが返る。** 認識精度で差は付かない。
海外で成立するとすれば **R2 のループと蔵書庫**が本体。

### ループに構造的な摩擦がある

R2 は「作る → 店の味と比べる → 言語化する」を要求するが、
**家で作る頃には店の味の記憶が薄れている**。米国は家庭料理の頻度も日本より低い。

R1 で店の写真を自動で添える設計はこの摩擦への正しい対処だが、記憶の減衰自体は解けていない。

### 注目の在り処が違う

海外のレシピ発見は**動画（TikTok / Instagram / YouTube）が主戦場**。
テキストのレシピ蔵書は発見の入口にならず、「作った後の道具」に留まりやすい。

## 4. 持っていけない機能・欠けている機能

### 持っていけない（海外版では出さない）

| 機能           | 理由                             |
| -------------- | -------------------------------- |
| JAN バーコード | 日本の商品コード                 |
| レシート OCR   | 日本のレシート書式・半角カナ前提 |
| 名寄せ辞書     | 「たまご→卵」の日本語辞書        |

在庫・買い物リストの一群がまるごと日本結合。ただし**主役ではないので外せる**。
設計上も「在庫は2階層目」と決めてあり整合する。

### 欠けている（海外に出すなら実装が前提）

**アレルギー・食事制限の扱いがコードに一切ない。**
（`grep -riE "allerg|vegan|vegetarian|halal|gluten"` → 該当なし）

欧米では食アプリの前提条件であり、**AI がレシピを生成する**本アプリではより重い。

- 写真から推論した材料に、食べられないものが入りうる
- R2 で「もっとコクを」と言われて乳製品を足す提案をしうる
- **健康被害に直結する領域**で、「AIが作ったレシピです」の注意書きだけでは足りない

### 単位系は「翻訳」ではなく「正しさ」

AI は「180度」「大さじ1」を出す。米国利用者に 180°F と読まれれば**料理が失敗する**。
tbsp も英 15ml / 豪 20ml で違う。R2 は分量を具体値で変える機能なので、
単位系が曖昧だと**機能の根幹が壊れる**。

## 5. 費用

**AI 上限は全世界合計 30 回/日**（`INFER_GLOBAL_DAILY_LIMIT`）。
海外に開けば初日で溶ける。収益は広告のみ（方針A）で、AI コストを賄う見込みは立っていない。

**利用者が増えるほど持ち出しが増える構造。** 海外展開は
「AI コストを誰が払うか」を先に決める必要がある。

## 7. 段階計画（着手する場合）

**前提: 日本語版で再現ループが1周した実績を得てから。**
摩擦の大きいループが実際に回るかは言語に関係なく未検証で、回らないなら英語化しても回らない。

| 段階   | 内容                                                              | 備考                                                     |
| ------ | ----------------------------------------------------------------- | -------------------------------------------------------- |
| **P0** | アレルギー・食事制限（プロフィール→プロンプト）                   | **日本語版にも価値がある**・海外は前提                   |
| **P1** | 単位系の抽象化（metric / imperial・℃/℉）                          | 同上。後の英語化が翻訳だけで済む                         |
| **P2** | i18n 基盤導入＋UI 文字列の外部化                                  | 実測 **2,883 箇所 / 178 ファイル**。放置すると増え続ける |
| **P3** | AI プロンプトの英語版                                             | **R0 のハーネスを英語で回して品質再測定が必須**          |
| **P4** | 配信国の設定（**EU 除外**）・ストア掲載の英語版・アイコン差し替え | R4 と同じ性質（公開物・ユーザー承認要）                  |
| **P5** | 検索・名寄せ・レシートの言語対応                                  | 作り直しに近い。**後回しでよい**                         |

**P0 と P1 は先に入れる価値がある。** どちらも日本語版に効き、海外に出るなら必須。
**P2 以降は日本語版の手応えが出てから。**
